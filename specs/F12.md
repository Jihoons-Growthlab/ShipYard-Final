# F12 건의·문의

이미지: inquiry-user, inquiry-admin. 메뉴 `건의·문의`(M95, token `inquiry`, 최상위). 권한: 모든 그룹 Write(작성·본인 글), ADMIN Admin(전체·처리). 규칙 BR-11.

## API

| 요청 | 비고 |
| --- | --- |
| `GET /api/inquiries?status&q&mine` | `{items,total,counts:{OPEN,IN_PROGRESS,DONE,REJECTED},is_admin,categories,statuses}`. 비관리자·mine=true는 본인 글만. counts는 상태 필터 전 기준. q는 제목+내용+작성자명. InquiryId 내림차순 |
| `POST /api/inquiries` | `{category,title,content}` 201 |
| `GET·PATCH·DELETE /api/inquiries/{id}` | DELETE 204 |

항목: inquiry_id, category, title, content, status, create_user_id, create_user_nm, create_dt, modify_dt, answer, answer_user_nm, answer_dt, mine.
categories `{BUG:오류 신고, FEATURE:기능 건의, QUESTION:사용 문의, ETC:기타}`, statuses `{OPEN:접수, IN_PROGRESS:처리중, DONE:완료, REJECTED:반려}`.

## 규칙

| 조건 | 결과 |
| --- | --- |
| 분류 없음·잘못됨 / 제목 없음 / 내용 없음 | 400 `분류를 선택하세요.` / `제목을 입력하세요.` / `내용을 입력하세요.` (앞뒤 공백 제거, 제목 200·내용 5000자) |
| 남의 글 조회(비관리자) | 403 `본인이 작성한 글만 볼 수 있습니다.` |
| 분류·제목·내용 수정 | 작성자만(403), OPEN일 때만(409 INVALID_STATUS `접수 상태인 글만 수정할 수 있습니다.`). ModifyDt 갱신 |
| status·answer 변경 | 관리자만(403 `관리자만 처리할 수 있습니다.`). DONE·REJECTED는 답변 필수(400 `완료·반려 처리에는 답변을 입력하세요.`). 바뀌면 AnswerUserId·AnswerDt 갱신 |
| 삭제 | 관리자 언제나, 작성자는 OPEN만(409 `접수 상태인 글만 삭제할 수 있습니다.`) |
| 없음 | 404 INQUIRY_NOT_FOUND `글을 찾을 수 없습니다.` |

챗봇 접수(F13)는 같은 서비스로 글을 만든다: suggestion→FEATURE, inquiry→QUESTION, 제목은 내용 첫 줄 80자.

## 화면

제목 `건의·문의`, 설명(관리자) `회원의 건의·문의를 확인하고 상태와 답변을 처리합니다.` / (회원) `시스템 개선 건의나 사용 문의를 남겨 주세요. 관리자가 확인 후 답변합니다.`

- 도구줄: 상태 칩 묶음(회색 바탕 안 `전체 N`·`접수 N`…, 선택 칩 흰 바탕 pri-d 700), `제목/내용/작성자` 검색, 조회, 관리자만 `내 글만` 체크, 오른쪽 `+ 새 글 작성`.
- 본문 `1fr 460px`(1200px 이하 1열), 높이 100%: 왼쪽 표 No, 상태 배지(OPEN info·IN_PROGRESS warn·DONE ok·REJECTED bad), 분류 칩(BUG 빨강·FEATURE 보라·QUESTION 하늘·ETC 회색), 제목(굵게, 말줄임), 작성자(관리자만), 작성일, 답변일. 빈 경우 `아직 작성한 글이 없습니다.`/`조건에 맞는 글이 없습니다.`
- 오른쪽 카드:
  - 빈 상태: `목록에서 글을 선택하거나 새 글을 작성하세요.`(관리자 `…글을 선택해 처리하세요.`) + `오류 신고 · 기능 건의 · 사용 문의 · 기타`.
  - 작성/수정: 분류 select(기본 FEATURE), 제목(placeholder `한 줄로 요약해 주세요`), 내용 10줄, 등록/저장 + 취소. 토스트 `등록되었습니다. 관리자가 확인 후 답변합니다.` / `저장되었습니다.`
  - 보기: 상태·분류·`No.N`, 제목 15px, `작성자 · 현지 시각 [· 수정 시각]`, 내용(연회색 박스, 줄바꿈 유지), 답변 있으면 초록 왼쪽 선 `관리자 답변` 박스(처리자·시각), 없고 비관리자면 `관리자가 확인 중입니다. 답변이 등록되면 여기에 표시됩니다.` 본인·OPEN이면 수정·삭제.
  - 관리자 처리: 점선 위 `처리`, 상태 4단계 버튼(선택 시 OPEN pri·IN_PROGRESS warn·DONE ok·REJECTED err 배경), 답변(완료·반려 시 `*`), `처리 저장`·삭제. 토스트 `처리 내용을 저장했습니다.`
- 삭제 확인 `"{제목}" 글을 삭제합니다.` 시각은 서버 UTC를 브라우저 현지 `YYYY-MM-DD HH:MM`으로 표시.

## 수용 기준

INQ-T01 작성 검증·공백 제거. T02 조회전용 그룹도 작성, 남의 글 403. T03 OPEN에서만 작성자 수정·삭제(이후 409). T04 관리자 완료·반려 답변 필수, 처리자·시각 기록. T05 counts 상태별 정확.
