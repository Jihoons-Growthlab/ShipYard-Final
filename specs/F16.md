# F16 시연 모드와 예시 데이터

실제 데이터와 섞이지 않도록 모두 **명시적 옵션**으로만 동작한다.

## init-db 옵션

`init-db --seed [--demo-pdfs] [--demo-usage]` — 각각 반복 실행해도 안전(이미 있으면 건너뜀).

### --demo-pdfs (예시 도면 PDF)

파일 없는 모든 리비전(시드 79개)에 도면 모양 PDF를 만들어 붙인다. FileNm `{도면번호}_Rev{n}.pdf`. 라이브러리 없이 PDF 1.4를 직접 쓴다(객체 6개 + Info, xref 정확히). 기본 Type1 글꼴(Helvetica/-Bold)이라 **글자는 ASCII만**.

- A3 가로 1191×842pt. 이중 테두리, 오른쪽 아래 표제란 400×160(PROJECT HULL n / DRAWING TITLE `{분야 영문} - BLOCK {코드|GENERAL}` / DRAWING NO / REV n STATUS / DESIGNED BY 사번 / DATE 배포일|작성일), 왼쪽 아래 `SWP SHIPYARD | SAMPLE DRAWING FOR DEMONSTRATION - NOT FOR CONSTRUCTION`, 오른쪽 위 리비전 표(그 리비전까지 최근 5개).
- 분야 영문: HULL STRUCTURE, PIPING ARRANGEMENT, ELECTRICAL WIRING, MACHINERY ARRANGEMENT, OUTFITTING ARRANGEMENT.
- 그림(표제란과 겹치지 않게 x<700 영역): HULL 측면 선체 윤곽+프레임 점선+갑판, 이 블록을 빨간 사각형(`THIS BLOCK`), 아래 평면도 / PIPE 배관선·밸브(나비 기호)·펌프 원 / ELEC 패널 3개·배선·부하 원 / 그 외 사각형 6개.
- 미배포 리비전은 빨간 도장 `DRAFT`·`FOR REVIEW`·`APPROVED - NOT ISSUED`·`SUPERSEDED`. Info `/Title({도면번호} Rev{n})`(뷰어 제목줄에 표시됨).

### --demo-usage (예시 사용 로그·건의 글)

- 예시 로그가 없을 때만, 난수 시드 7로 최근 30일 TB_SYS_LogApi에 `DemoYN=1`로 넣는다. 회원별 하루 평균 호출 park.pm 60·han.wk 45·lee.dwg 50·choi.qa 18·admin 14(가우스 σ=25%, 최근 7일 ×1.1), 주말 85% 쉼, 한국시간 7~19시(평균 13시 σ3), 오류 3%(400/403/404/409/500), GET 응답 ms lognormal(3.2,.5), 그 외 (3.7,.5). 회원별 주 사용 경로(가중치)는 업무에 맞춘다(공정관리자→간트·일정, 현장→실적 입력, 도면→도면·PDF·결재, 조회전용→대시보드·호선, 관리자→회원·건의). 공통 경로(로그인·메뉴·코드·날씨)는 가중치 3.
- 건의 글 4개(제목이 없을 때만, 6일 전부터 하루 간격):

| 작성자 | 분류 | 제목 | 상태 / 답변 |
| --- | --- | --- | --- |
| park.pm | FEATURE | 공정 계획 엑셀 내보내기 요청 | IN_PROGRESS / 검토 중입니다. 다음 배포에 포함할 예정입니다. |
| lee.dwg | BUG | 도면 PDF 업로드 시 파일명이 깨집니다 | OPEN / - |
| han.wk | QUESTION | 실적 입력 마감 시간이 있나요? | DONE / 마감 시간은 없습니다. 다만 주간 보고 전(금 17시)까지 입력해 주세요. |
| choi.qa | ETC | 대시보드 글자 크기 조정 | REJECTED / 브라우저 확대(Ctrl +)로 조정해 주세요. 별도 설정은 제공하지 않습니다. |

내용: 각각 `간트 화면의 공정 목록을 엑셀로 내려받을 수 있으면 주간 회의 자료 만들기가 편할 것 같습니다.` / `한글 파일명으로 업로드하면 목록에서 파일명이 ??? 로 보입니다.` / `전날 실적을 다음날 오전에 입력해도 되는지 궁금합니다.` / `회의실 화면에서 대시보드 숫자가 작게 보입니다.` 답변자 admin, 답변 시각 작성 5시간 뒤.

## 데모 역할 전환

- `scripts/demo.sh`: `SHIPYARD_DB_PATH=state/run/demo.db`, `SHIPYARD_FILE_DIR=state/run/demo-files`, `SHIPYARD_DEMO=1`, 포트는 `SHIPYARD_BACKEND_PORT`(기본 8100). DB가 없으면 `--seed --demo-pdfs --demo-usage`로 만들고 모든 회원 disabled, admin·han.wk만 approved·OTP 끔·비밀번호 `Shipyard-Demo-26!`. 그 뒤 uvicorn.
- 조건(둘 다): 환경 `SHIPYARD_DEMO=1` **그리고** DB 경로가 정확히 `state/run/demo.db`. 이때만 `GET /api/auth/me`에 `demo_role`(admin→`admin`, han.wk→`user`)을 넣는다.
- `POST /api/auth/demo-role {role:admin|user}`: 조건 불충족·대상 없음(approved·OTP 끔)이면 403. 현재 접속 로그에 LogoutDt(1건만 갱신돼야 함) → 대상 사용자로 새 LogAccess → 새 전체 토큰.
- 헤더: demo_role이 있으면 로그아웃 앞에 `관리자`/`사용자` 토글(현재 역할 흰 바탕·비활성). 전환 시 토큰 교체, 탭 상태 초기화, 새로고침.
