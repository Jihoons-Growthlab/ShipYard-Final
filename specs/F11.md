# F11 사용 로그 대시보드

이미지: usage-log. 권한: M92 Admin(메뉴 `시스템 > 사용 로그`, token `usage-log`). 규칙 BR-10.

## 기록

- 미들웨어 하나가 모든 `/api` 호출 뒤 `TB_SYS_LogApi`에 한 행을 남긴다: EmpNo(인증된 요청만, `current_user`가 `request.state.emp_no`에 넣는다), Method, Path(**라우트 템플릿** 예 `/api/plans/{plan_id}`, 실제 값 아님), Status, DurationMs, CallDt(UTC `YYYY-MM-DD HH:MM:SS`).
- `/api/health`, `/api/usage/*`는 기록하지 않는다. 기록은 스레드풀에서 하고, 실패해도 응답에 영향이 없다(예외를 삼킨다). 본문·토큰·쿼리 값은 저장하지 않는다.

## API

`GET /api/usage/summary?days=7|30|90&emp_no=` (그 외 days 400 `조회 기간은 7, 30, 90일 중 하나입니다.`) → 

```text
days, emp_no, since
kpi = {calls, users(호출한 회원 수), logins(LogAccess 로그인 수), errors(Status>=400), error_rate(%, 소수 1), avg_ms}
daily[days개, 한국시간 날짜 오름차순, 빈 날 0] = {date, calls, errors, users}
hours[24] = 한국시간 시각별 호출 수
features[] = {feature, calls, paths}  호출 수 내림차순
top_users[≤10] = {emp_no, display_name, calls, last_dt, top_feature}
endpoints[≤15] = {method, path, calls, errors, avg_ms, max_ms, feature}
menus[] = {menu_id, title, opens, users}   TB_SYS_LogMenuAccess 기준
recent_errors[≤10] = {call_dt, method, path, status, emp_no, display_name}
demo_calls = DemoYN=1 행 수
user_options[] = {emp_no, display_name}
```

emp_no를 주면 모든 집계를 그 회원으로 제한한다. 기능 이름은 경로 접두어 표(앞에서부터 첫 일치)로 정한다:

| 접두어 | 기능 |
| --- | --- |
| /api/hulls/{hull_no}/plans, /api/plans, /api/plan-hulls, /api/procs | 공정 계획 |
| /api/progress | 공정 실적 |
| /api/hulls, /api/blocks | 호선 관리 |
| /api/drawings / /api/approvals / /api/dashboard | 도면 관리 / 결재 / 대시보드 |
| /api/users, /api/auth-groups | 회원관리 |
| /api/auth / /api/inquiries / /api/chat | 로그인·인증 / 건의·문의 / 챗봇 |
| /api/me, /api/codes / /api/weather / 그 외 | 공통(메뉴·세션) / 날씨 / 기타 |

## 화면

제목 `사용 로그`, 설명 `누가 어떤 기능을 얼마나 썼는지 API 호출·메뉴 진입 기록으로 봅니다. (관리자 전용)`.

- 도구줄: 기간 select(최근 7/30/90일, 기본 7), 사용자 select(`사용자 전체` + `이름 (아이디)`), `새로고침`, 필터 중이면 `필터 해제`. 오른쪽 demo_calls>0이면 b-warn `예시 데이터 N건 포함`.
- KPI 5열: API 호출(`최근 N일`), 사용자, 로그인, 오류율(`오류 N건 (4xx·5xx)`, 5% 이상 err), 평균 응답(ms, 500 이상 err). 카드 왼쪽 3px pri 선(err면 err).
- 2:1 행: `일별 호출 추이` SVG(viewBox 640×200, 영역 그라데이션 + 선 + 오류 막대(#fca5a5) + y눈금 0/½/최대(10^n 올림) + x라벨 7일 이하 매일·30일 5일·90일 15일 간격). 날짜에 올리면 점선 안내선·점·툴팁 `날짜 / 호출 N · 오류 N · 사용자 N`. / `시간대별 호출 (한국 시간)` 24개 세로 막대, 최댓값 진하게, 3시간마다 라벨.
- 3열: `기능별 사용`(상위 10, 팔레트 10색 가로 막대) / `사용자별 호출 TOP 10`(이름 + 작은 글씨 주 사용 기능, 클릭 시 그 사용자로 필터·다시 클릭 해제, 선택 행 강조) / `메뉴 진입`(청록 막대, `N / M명`). 빈 경우 `기록이 없습니다.`
- 2:1 행: `많이 호출된 API TOP 15` 표(기능, 메서드 배지(GET 하늘·POST 초록·PATCH/PUT 노랑·DELETE 빨강) + 경로 monospace, 호출, 오류(있으면 err), 평균 ms, 최대 ms) / `최근 오류`(상태 배지 5xx bad·4xx warn, 요청, `이름 · 현지 시각`, 없으면 `오류가 없습니다.`).
- 막대는 grow 애니메이션(ui.md 모션). 1200px 이하 KPI 3열, 나머지 1열.

## 수용 기준

USAGE-T01 인증 호출이 사용자·템플릿 경로로 기록, health 미기록. T02 비관리자 403(메뉴·API). T03 days 검증, emp_no 필터 시 top_users가 그 사람뿐. T04 예시 로그 포함 시 demo_calls>0과 배지.
