# F14 보고서 작성 (PDF · Excel)

이미지: chat-report. 챗봇(F13)의 `📄 보고서 작성하기`에서 쓴다. 생성은 MCP `build_report` 도구.

## API

| 요청 | 비고 |
| --- | --- |
| `GET /api/chat/report/options` | 로그인. `{hulls:[{hull_no,hull_nm}](M11 View일 때만, UseYN=1 번호순), formats:[{code:pdf,name:PDF},{code:xlsx,name:Excel}]}` |
| `POST /api/chat/report` | `{format:pdf|xlsx, hull_no?≤20}` → 201 `{report_id(hex24), format, filename, title, size, summary:{hulls,plans,delay,waiting,drawings,unissued}, download_url}`. 도구가 `{error,status}`면 그 상태로 `REPORT_ERROR` |
| `GET /api/chat/reports/{report_id}?format=` | 만든 사용자만. 파일 응답. id 형식(^[0-9a-f]{24}$)·파일 없음은 404 REPORT_NOT_FOUND |

파일 위치 `<SHIPYARD_FILE_DIR의 부모>/reports/<사번(안전 문자만)>/<report_id>.<ext>`. 경로 탐색 차단.

## 내용

- 범위: hull_no가 있으면 그 호선만(없으면 404 호선 없음), 없으면 UseYN=1 전체.
- 섹션은 권한별: 호선(M11), 공정(M21), 도면(M31) View. 셋 다 없으면 400 `보고서에 넣을 수 있는 메뉴 권한(호선·공정·도면 조회)이 없습니다.` 빠진 영역은 `조회 권한이 없어 제외: …`로 표시.
- 제목 `{호선} 호선 현황 보고서` / `전체 호선 현황 보고서`. 파일명 `{제목 공백→_}_{YYYYMMDD_HHMM}.{ext}`(한국시간). 작성자 이름, 기준일.
- KPI: 호선 수, 공정 수, 지연 공정, 도면 대기 공정(drawing_wait), 도면 수, 미배포 도면(ISSUED·OBSOLETE 제외).
- 표 머리: 호선 `호선번호, 호선명, 선종, 상태, 선주, 인도예정, 진척률, 지연` / 공정 `호선, 블록, 공정, 계획 시작, 계획 종료, 진척, 상태, 담당자, 미배포 필수 도면` / 도면 `도면번호, 도면명, 호선, 블록, 분야, Rev, 상태, 설계자`. 코드는 코드명으로, 진척은 정수면 `100%`.
- 단일 호선이면 주요 일정(일정, 계획, 실적, 차이(일)).

PDF(fpdf2, A4 가로): navy 머리띠에 제목·`작성 … · 작성자 … · 기준일 …`, KPI 카드 6개(왼쪽 색 선, 지연·대기·미배포 값 있으면 주황/빨강), `공정 상태 분포` 100% 가로 막대(상태색, 폭 22mm 넘으면 `상태명 N` 흰 글씨), 섹션 표(머리 navy·흰 글씨, 줄무늬 #f4f7fb — 직전 도형 채움색이 이어지지 않게 명시), 지연 상태 빨강, 꼬리말 `SWP 조선소 통합관리 · {제목} · N쪽`. 문서 제목·작성자 메타데이터.
한글 글꼴: `SHIPYARD_REPORT_FONT` → `/System/Library/Fonts/AppleSDGothicNeo.ttc`(collection 0) → Nanum/Noto 경로 순. `AppleGothic.ttf`는 OS/2 테이블이 없어 fpdf2에서 실패하므로 쓰지 않는다. 없으면 400 안내.

Excel(openpyxl): 시트 `요약`(제목 16pt, 작성 정보, KPI 머리·값, 공정·도면 상태별 건수, 주요 일정, 제외 안내), `호선`·`공정`·`도면`(권한 있는 것만, 머리 navy 흰 굵게, 얇은 테두리, 열 너비, 머리행 고정, 자동 필터, 지연 상태 빨강).

## 화면 `components/ChatReport.vue`

챗봇이 `보고서 작성하기` 사용자 말풍선과 안내 `보고서 범위와 형식을 골라 주세요. 권한이 있는 호선·공정·도면 현황을 담아 만들어 드릴게요.` 아래에 카드를 띄운다.

- `범위` 알약: `전체 호선` + 호선번호(제목 툴팁 호선명). `형식` 2칸: `[PDF] 문서로 보기·인쇄`(빨강 아이콘), `[XLS] Excel로 편집`(초록). `보고서 작성하기`(생성 중 `보고서를 만드는 중…`).
- 결과: 형식 아이콘, 제목, `파일명 · NKB`, `호선 N · 공정 N · 지연 N · 도면 N`, `다운로드`(blob → a[download] 파일명), `다른 보고서`. 오류는 카드 안 빨간 박스.

## 수용 기준

REPORT-T01 MCP 경유 PDF(%PDF)·XLSX(시트 4개, 호선 시트 6행) 생성·다운로드. T02 다른 사용자 다운로드 404, 잘못된 id 404. T03 잘못된 형식 422, 없는 호선 404. T04 권한 없는 섹션 제외. 생성 파일을 이미지로 렌더링해 한글·표를 눈으로 확인한다.
