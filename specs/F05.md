이미지: plan-gantt, plan-hover, plan-zoom, plan-selected, plan-new, plan-drawing-wait. 권한: 조회 M21 View, 쓰기 M21 Write. 규칙 BR-01~04, 08.

공정 응답: plan_id, hull_no, block_id, block_cd, block_nm, proc_cd, proc_nm, label, plan_start_dt, plan_end_dt, actual_start_dt, actual_end_dt, progress_rate, plan_status, manager_emp_no, manager_nm, remark, create_user_id, create_dt, pred_plan_ids, gate_ok, blockers[{drawing_id,drawing_no,dwg_status}], drawing_wait(PLAN이고 blocker 있음).

정렬: 블록코드 숫자순(비숫자 뒤), 블록 없는 공정은 맨 뒤, 그다음 표준공정 Seq, PlanId.

연계 응답: `{plan_id,blockers,links:[{drawing_id,drawing_no,drawing_nm,dwg_status,has_issued,required,need_dt}],available:[같은 호선 미연계 도면]}`.

## 규칙

- 입력: `block_id, proc_cd, plan_start_dt, plan_end_dt, manager_emp_no, remark, pred_plan_ids, confirm_late_preds`. 신규 PLAN·진척 0.

| 조건 | message |
| --- | --- |
| 시작/종료 없음 | 계획 시작/종료일을 입력하세요. |
| 종료 < 시작 | 계획 종료일이 시작일보다 빠릅니다. |
| 다른 호선 블록 | 해당 호선의 블록이 아닙니다. |
| 공정 코드 | 허용되지 않는 공정 코드입니다. |
| 담당자 미승인 | 승인된 회원만 담당자로 지정할 수 있습니다. |
| 자기 참조 | 자기 자신을 선행 공정으로 지정할 수 없습니다. |
| 다른 호선 선행 | 선행 공정은 같은 호선의 공정이어야 합니다. |
| 순환 | 선행 공정이 순환 구조를 만듭니다. |
| 늦은 선행(409) | 선행 공정 종료일이 이 공정의 시작일보다 늦습니다. 그대로 저장할까요? |

- 수정은 진척·실제일을 보존한다.
- schedule: 기간 검증은 위 표와 같다. 시작일이 바뀌면 이 공정의 기존 선행으로 늦은 선행 409를 검사한다(confirm으로 통과). 그 뒤 후행 연쇄(BR-04)를 한 트랜잭션으로 저장하고 BR-03 재계산.
- 연계: 같은 호선만(`같은 호선의 도면만 연계할 수 있습니다.`), 중복 409(`이미 연계된 도면입니다.`), `NeedDt=PlanStartDt`, 없으면 404 PLAN_NOT_FOUND·DRAWING_NOT_FOUND·LINK_NOT_FOUND.

## 화면

제목 설명 `막대 또는 좌측 공정명을 클릭하면 아래에 상세·수정 패널이 열립니다.` 화면은 높이 100%로, 간트가 남은 높이를 쓰고(min 140px) 패널이 아래 붙는다.

- 도구줄: 호선 select(기본: param 호선, 없으면 공정 있는 첫 호선), 블록 전체 select, 배율 select(축소 2.5 / 보통 4 / 확대 6 px/일, 기본 4), `호선 진척` + 170px 진척 바, 오른쪽 `+ 공정 추가`(쓰기).
- 호선 변경 시 블록·선택·스크롤을 초기화한다. 이동으로 들어온 param을 재적용한다.
- 범례(12px): 상태 5색(바 12×10px), `📐 도면 대기`, `토요일`, `일요일·공휴일`(음영 견본), muted `— 선후행 연결선 / 빨간선 = 오늘({today})`. 바 색은 F03의 공정 색.
- 오늘선 2px + 붉은 그림자, `오늘` 라벨은 빨간 알약(흰 글자). 월 헤더 11px 600 #475569. 행 호버·관련 행 연한 파랑.

간트 계산:

- 시작 = min(오늘-5일, 공정 시작)이 속한 달의 1일. 끝 = max(오늘+5일, 공정 종료). 총 일수 = 끝-시작+8.
- 폭 = 230 + ceil(총 일수 × 배율). 행 높이 28px, 헤더 34px, 왼쪽 열 230px.
- 월 헤더 `YYYY.MM`(11px), 월 경계 점선. 왼쪽 열·헤더 sticky.
- 막대: 위 6px, 높이 16px, radius 5px, 트랙은 상태색 28%와 흰색 혼합 + 상태색 45% 안쪽 테두리 + 그림자, 내부 채움 = 진척 폭(상태색 세로 그라데이션, 로드 시 grow-x). 호버 시 1px 떠오르고 상태색 그림자. 선택 막대는 흰 2px + 상태색 4px 링. left·width 전환 .28s(드래그 중에는 끔).
- 진척 라벨: 막대 끝 +6px에 10px `N%` muted, 행 호버·선택·관련 행에서만 보임.
- 드래그(쓰기 권한): 막대 가운데 = 이동, 양 끝 6px 핸들(호버 시 상태색 + 흰 세로 눈금) = 시작/종료만. 3px 넘게 움직여야 드래그(아니면 클릭). 하루 단위 `round(dx/배율)`, 기간 최소 1일. 끄는 동안 막대 위 진한 라벨 `시작 ~ 종료`, 막대 그림자. 놓으면 schedule 호출 → 409면 `confirm` 후 재전송(취소 시 원위치) → 토스트 `저장되었습니다.` 또는 `저장되었습니다. 후행 공정 N건의 일정이 함께 조정되었습니다.` → 재조회(스크롤 유지), 패널이 열려 있으면 다시 채움. 드래그 직후 click은 무시.
- 마우스오버 카드(ui.md 공통, 폭 400·높이 380, 드래그 중 숨김): 라벨 + 상태 배지 + 📐 / 계획 `시작 ~ 종료 (N일)` / 실제 / 진척 바 / 기준일이 종료 지나고 DONE 아니면 빨강 `종료 예정일 N일 경과` / 담당자(`미지정`) / 선행·후행 라벨 / 비고(줄바꿈 유지) / blocker warn / 연계 도면 표(도면, 상태+미배포, 필수/참고 — 로더는 `GET /api/plans/{id}/drawings`, 그 외는 화면 데이터) / `클릭하면 수정 패널이 열리고, 끌면 일정을 옮깁니다.`(조회 전용 `클릭하면 상세 패널이 열립니다.`). 막대 title 툴팁은 쓰지 않는다(aria-label).
- 휴일: 타임라인 하루 폭 세로 띠 — 토 rgba(100,116,139,.13), 일·공휴일 rgba(220,38,38,.07)(공휴일이 우선). 헤더 아래 6px 빨간 표시(공휴일, 폭 max(배율,3), title `날짜 이름`). 공휴일 표는 `utils/holidays.js`(아래), 표에 없는 해는 주말만.
- 빨간 오늘선 2px, `오늘` 라벨. 처음 스크롤은 오늘선이 보이는 폭의 40% 위치.
- 선후행선: 선행 종료+1일 지점의 행 중앙 → 4단위 오른쪽 → 수직 → 후행 시작까지. 1px #64748b opacity .5, round join, 끝에 화살표 marker. 마우스를 올린(없으면 선택한) 공정의 선·후행 연결은 pri 1.6px 불투명 + 파란 화살표로 맨 위에 그리고 관련 행을 연하게 칠한다. 막대·행 뒤로 클릭을 막지 않는다. `depPaths`는 `{d,from,to}`를 돌려준다.
- 행: `블록코드` muted + 공정명, blocker 대기 행은 `📐`. 호선 전체 공정은 `호선`. 막대 title에 라벨·기간·진척·상태·도면 대기.
- 재조회·저장 후 가로 스크롤을 유지한다. 공정이 없으면 `표시할 공정이 없습니다.`

패널(카드):

- 머리: 라벨(또는 `공정 추가`), 상태 배지, `진척 N% · 실제 시작 ~ 종료`.
- 본문 `1fr 430px`, gap 16.
- 왼쪽 6열 폼: 블록(2), 공정, 계획 시작, 계획 종료, 담당자 / 선행 공정 (Ctrl 다중선택)(3, 높이 66), 비고(3, 높이 66). 하단 저장, 삭제, 닫기. 1560px 이하 4열: 블록(2), 공정(2) / 시작, 종료, 담당자(2) / 선행(2), 비고(2).

- 오른쪽: blocker 시 warn 박스 `📐 도면 대기: 필수 도면 {번호(상태)} 미배포 → 착수 불가`. 제목 `연계 도면 (필수 도면은 배포 전 착수 불가)`. 표 r3: 도면번호(링크 → 도면 상세 모달), 상태 배지 + `미배포`(b-warn), 필수/참고, `해제`. 빈 경우 `연계된 도면이 없습니다.` 아래 도면 선택, `필수`(기본 체크), `+ 연계`.
- 신규 공정 오른쪽: `저장한 뒤 이 공정에 도면을 연계할 수 있습니다.`
- 늦은 선행 409는 `confirm` 후 재전송, 취소하면 변경 없음.

## 수용 기준

PLAN-T01 필터·선택·스크롤·오늘선. T10 드래그 연쇄: A(11-01~14)→B(15~20)→C(25~30), A를 11-07~20으로 → B 11-21~26, C 11-27~12-02, 무관 공정 그대로, 다시 앞당겨도 후행 유지, B를 선행보다 앞으로 409/확인 통과. T11 마우스오버 카드·선후행 강조. T12 2026-10-03(토·개천절) hol, 10-05 대체공휴일 hol, 10-04 sun, 10-10 sat. T02 기간 검증·담당자. T03 자기 참조·순환 거절. T04 늦은 선행 취소/확인. T05 선행 DONE + 필수 ISSUED → READY. T06 DRAFT만이면 PLAN, 배포 후 갱신. T07 삭제 후 고아 없음.
